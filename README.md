## This repo

Static site. HTML, CSS, and JavaScript only. No build step.

`index.html` is the page. `styles.css` is the layout and the light, dark, and system themes. `script.js` remembers the theme and opens the small-screen menu.

## Preview locally

Open the folder in VS Code, then right-click `index.html` and choose **Open with Live Server**.
